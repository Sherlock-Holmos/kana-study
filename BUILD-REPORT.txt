Japanese Study v12.0.0
======================

Major changes
-------------
1. Daily Planner with light / standard / intensive workload modes.
2. Daily sessions can combine due review, weak-item reinforcement and a recommended course.
3. Course metadata: objectives, prerequisites, estimated minutes, difficulty, mastery target.
4. SRS 2.0 evidence weighting by exercise type and response speed.
5. Skill state now tracks reviewCount, evidenceScore, averageResponseMs, lastResponseMs and lastQuality.
6. Listening workflow supports normal/slow playback and reveals transcript only after answering.
7. N5 completion metric combines six skill domains and curriculum completion.
8. Content governance metadata and CI validation.
9. schemaVersion upgraded to 12 with backward migration support.

Verification
------------
Run: npm run verify

Important limitations
---------------------
- Listening uses browser Web Speech API, not bundled human recordings.
- Corpus is a project-authored N5 core corpus, not an official JLPT exhaustive list.
- Automated validation does not mean every language item has been manually reviewed by a professional editor.
