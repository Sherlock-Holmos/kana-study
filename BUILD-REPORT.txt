Important product limitations
-----------------------------
1. Automated content validation is not professional teacher review. Current report: 0 human-reviewed / 1067 automated-validated.
2. The repository contains the Audio 3.0 fixed-audio abstraction but does not fabricate a human-recorded audio pack. Missing fixed audio uses Web Speech fallback.
3. Speaking recording is local and ephemeral. v16 intentionally does not claim automatic pronunciation scoring.
4. content/generated/ is an independently versioned JSON release artifact. Runtime content is still sourced from the existing JS content graph in v16; this preserves compatibility while establishing the future external-content boundary.
