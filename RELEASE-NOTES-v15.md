# Japanese Study v15.0.0 — N5 Learning Quality

v15 freezes the N5 platform architecture and focuses on learning quality.

## Major changes

- Data schema 13 with planner debt, ability profile, assessment diagnostics and incremental-sync metadata.
- Adaptive Planner 2.0 prioritizes overdue risk, recent mistakes and weak skills instead of forcing every overdue review.
- Review Debt makes large backlogs visible and spreads them across future sessions.
- Adaptive new-content budget reacts to recent accuracy and review backlog.
- Ability Profile separates active vocabulary production, grammar application, kanji reading, reading detail, listening time/number and other subskills.
- Pedagogy tags are automatically attached to the current N5 corpus for topic/ability diagnosis.
- Assessment 2.0 avoids recently used items when possible and produces ability-level diagnostics in addition to domain scores.
- Audio Layer prefers explicit audio assets when supplied and falls back to ja-JP Web Speech synthesis.
- Incremental sync tracks dirty skills, dates and sessions; first v15 sync remains a safe full sync.
- Content quality report is generated by `npm run content:report`.
- Production hashed build from v13/v14 remains intact.

## Scope deliberately not added

N4/N3 expansion, community, rankings and AI free-chat remain outside v15.
