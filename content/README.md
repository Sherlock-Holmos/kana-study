# Content release boundary

v15 introduces a content release boundary without forcing a risky runtime migration from the existing JS corpus.

- Runtime source of truth remains `src/data/*` for v15 compatibility.
- `content/release.json` is generated by `npm run content:report` and gives the app/content release an independent identity.
- Future N4/N3 work should migrate reviewed content into versioned JSON files behind the same pedagogy/content schema rather than enlarging application code indefinitely.
- `automated-validated` means structural/reference checks only; it is not a claim of professional teacher review.
